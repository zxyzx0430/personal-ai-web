## 学生版：必须全部保留的交互（旧版源码已核对）

- 翻页：上一页/下一页；单击十页导览及导览中的任意页；顶部品牌返回第一页；页面进度及标题同步；`#01`—`#10` 深链接及 `hashchange`；禁用无效的前后按钮。
- 键盘：`ArrowLeft/Right`、`PageUp/Down`、`Home/End`、`Escape`（打开十页导览）、`B`（静态模式）、`R`（重播）、`F`（全屏）。表单、视频、章节导航等聚焦时禁止抢键。
- 导航触控：电脑端达到阈值的滚轮翻页；移动端水平滑动翻页；竖向滚动及视频区域触摸不误翻页。
- 动画：逐页入场、每个特定章节的 SVG/路径及卡片动效、重播当前页、暂停/继续、切换静态模式、`prefers-reduced-motion` 变化监听、`learning-system-static` 的 localStorage 偏好、页面隐藏暂停、动效取消清理。
- Canvas：开场/尾页的粒子场；窗口 resize；暂停/静态/隐藏时停止 `requestAnimationFrame`；组件卸载时正确释放资源。
- 视频：内嵌 MP4，3 个 `data-video-time` 章节（0、3.2、11 秒），视频状态文字、播放/暂停/结束/错误反馈、章节高亮、视频全屏、翻页时暂停视频。
- 教学演示：可复制预览中的完整提示词，有浏览器权限/剪贴板失败时的文本选择回退；保留页内所有辅助说明和可点击跳页入口。
- 旧版包含 2 个 Canvas、1 个内嵌 MP4 与 1 张内嵌图片；图片和视频已拆出并做 SHA-256 校验，资源尚未完成浏览器播放验收。
