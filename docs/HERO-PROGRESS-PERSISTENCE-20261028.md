# 首页动画状态持久化修复（2026-10-28）

## 修复目标

用户在第一页看完「一项问题 → 三类原因 → 五步学习闭环」动画后，翻往其他页面再返回，不应重新播放。中途手动切换的动画阶段和五步当前位置也必须保持。

## 行为

- 完整看过最后一步后，将 `completed` 记为 true；再次返回第一页或刷新页面时，直接显示最后停留的阶段及步骤，不重新触发标题的模糊入场和文字打字效果。
- 只看过部分阶段时，保留 `stage`、`step`、`manual`；手动控制过的状态不会在返回时意外变回自动播放。
- 自动播放部分观看后离开，也可以从离开时的阶段与步骤继续，而不是重置到第一张卡。
- localStorage 仅保存动画进度，不保存浏览者身份或问卷内容。不同浏览器或清除站点数据后会视为新的浏览环境。
- 显式调用已有 `replay()` 能清除保存状态重新播放；本轮不新增任何客户可见的重播控制。

## 工程

- `src/animation/heroProgress.ts`：轻量版本化存储，验证字段范围，允许存储不可用时正常显示动画。
- `src/animation/AnimationDirector.ts`：页面切换/浏览器返回时使用持久化进度恢复第一页阶段和暂停状态，不再无条件重置到零。
- `src/animation/SceneMotifs.tsx`：恢复 1→3→5 阶段、当前五步位置、手动控制状态；记录进度；对已看过的场景取消首次显现动画。
- `src/pages/AboutPage.tsx`：已完成首屏的标题、正文、按钮改为立即完整呈现。

## 验证

- 正式站发布需经 `personal-ai-web/main` 与 `personal-ai-study-site` 工作流；旧版本保留在备份分支。
