# Personal AI System｜家长需求式获客首页（React 独立支线）

## 安全边界

- 开发分支：`feature/parent-acquisition-story-v1`，基于已验收动画分支 `feature/react-motion-system` 的 `acb649f`。
- 不改 `main`、正式站 `ai.zxyzx.me`、历史 HTML 实验站或原 React 动画预览站。
- 独立 HTTPS 验收地址：`https://acquisition-preview.67.215.236.125.sslip.io/?view=about`。
- 保留原先七页内容快照 `src/content/about-pages-original/*.html`。项目中还保留完整 `src/content/about.html`。
- 保持原 `AnimationDirector`、`HeroMorph`、`FanCard`、`NarrativeHeading` 等组件的时间节奏、贝塞尔整页翻页、不闪现状态、Reduced Motion 和原页路由。**不修改动画库的时间轴。**

## 为什么调整

旧叙事强调“项目—方法—六方向—PDF—视频—联系”，但首次浏览的家长不一定知道自己为何要继续阅读。本版改为“真实学习问题—差异化诊断—具体示意—可观察的第一次体验—独立验证与长程系统—证据与资料—交流一个问题”。

## 页面与工程

- `scripts/build-acquisition-pages.py`：从备份的原版七页抽取保留内容，组合新的七页 HTML，校验三份 PDF、视频和六大方向仍然存在。
- `src/components/AcquisitionStory.tsx`：四张原问题卡仍由 `FanCard` 动画；展开区解释可能原因、来源于演讲的示意、独立验证方式，附现有抖音视频链接和**参考**时间段。学生 A/B 切换通过 React state 与 Motion 实现。
- `src/pages/AboutPage.tsx`：仅新增内容替换节点，不重写主状态机、页面进入退出、文字入场和原有资源复制。
- `src/styles/acquisition.css`：沿用米白、克莱因蓝及现有排版规则；补回旧全屏样式覆盖掉的内容页横向边距。独立页与首页 ShadowRoot 同时导入。
- 本轮不新增外部 tracking SDK、不收集学生个人数据。真实转化率需要后续获取匿名漏斗数据才能评价。

## 讲解素材依据与表述边界

- 现有完整讲解视频入口：`https://v.douyin.com/rtKle9ly734/`（参考现有网页，第六页仍完整保留）。
- 参考段：四个困境约 01:40–02:50；学生 A/B 函数约 05:05–06:10；二次函数可视化约 06:15–08:10；错因与学习记录约 08:15–10:20；反馈时效约 12:00–13:30。
- 视频链接为**原完整视频**，目前没有为这些段落生成单独切片。时间是参考定位，需要按实际成片核对，不承诺点击即精准跳转该时刻。
- A/B 与学习流程属于**教学示意**，没有宣称真实学员或提分成效。外部研究来源不作为对独立项目效果的背书。

## 测试边界

- 主要验收：1440×900、1280×720、390×844、360×740；四问题展开、视频链接、A/B 切换、六方向展开、五环节保留、PDF 可打开、联系模板、弹性边距、无整页溢出。
- 同时回归 `/study/`、`/adult/`、`/needs/` 和首页 ShadowRoot。页面跨越大于视口时保持原生内部阅读模式。
- 因果动画现有机制保持不动；新增卡片细节只对交互区域自身进行展开/收起，不复刻任何旧 HTML 运行时脚本。

## 后续可验证的获客假设

用户从首屏的学习问题进入后，更愿意点击哪一类困境、看哪一段解释、进入需求指南还是直接咨询？后续可选加第一方匿名事件统计，不采集学生隐私，先有样本再讨论转化效果。用户验收前不合并正式网站。
